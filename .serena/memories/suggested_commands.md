# Suggested Commands

- `serena open_dashboard`: Monitor Serena MCP logs and tool usage.
- `serena get_current_config`: Check agent/project configuration.
- `task`: Delegate tasks between agents (`manager`, `explore`, `godev`, etc.)
- `skill`: Load domain-specific instructions.
- `@historian`: Use for project memories and semantic search.
- `@explore`: Use for rapid context gathering.
